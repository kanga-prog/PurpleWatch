## Time correlation

PurpleWatch records controlled-test windows in UTC for cross-system correlation.

Example: `2026-09-06T23:40:46+02:00` local time equals `2026-09-06T21:40:46Z` UTC.

Alerts are accepted as evidence when endpoint, controlled behavior, process telemetry, Wazuh rule, ATT&CK mapping, and execution window correlate.

Small pipeline delay between process completion and Wazuh alert generation is expected.
