# PW-301 — Atomic Red Team Controlled Validation Framework

## Status

Validated on 2026-09-06 in the private PurpleWatch cyber lab.

No secrets, credentials, malware, raw Wazuh logs, or Atomic payloads are stored in this repository.

## Objective

Deploy a controlled Atomic Red Team framework on the Windows lab endpoint and validate a safe initial set of MITRE ATT&CK techniques through the existing Sysmon -> Wazuh telemetry pipeline.

## Lab endpoint

- Endpoint: `PW-WIN11-01`
- Platform: Windows 11 Enterprise Evaluation
- Monitoring: Sysmon 15.21
- Collection: Wazuh Agent 4.14.7
- Wazuh Manager: 4.14.7
- Environment: isolated/private VirtualBox cyber lab

## Controlled P0 technique validation

| ATT&CK technique | Atomic test | Execution | Sysmon | Wazuh alert | Expected ATT&CK mapping |
| --- | --- | --- | --- | --- | --- |
| T1082 — System Information Discovery | #1 | PASS | PASS | PASS | GAP |
| T1057 — Process Discovery | #2 | PASS | PASS | PASS | GAP |
| T1087.001 — Local Account Discovery | #10 | PARTIAL | PASS | PASS | PARTIAL |
| T1016 — System Network Configuration Discovery | #1 | PASS | PASS | PASS | GAP |
| T1059.001 — PowerShell | #17 | PASS | PASS | PASS | PASS |

### T1082

Atomic executed `systeminfo` and a registry query.

Sysmon recorded the expected processes.

Wazuh generated alerts, but the observed rules mapped the activity primarily to `T1059.003` and `T1087` rather than `T1082`.

Result: telemetry and alerting present, ATT&CK mapping gap.

### T1057

Atomic executed `tasklist`.

Sysmon recorded `tasklist.exe`.

Wazuh generated alerts, but the observed mapping identified command-shell/account-discovery techniques instead of `T1057`.

Result: telemetry and alerting present, ATT&CK mapping gap.

### T1087.001

Atomic test #10 executed `query user`.

The command returned no interactive users and exit code `1`, but Sysmon recorded both `cmd.exe /c query user` and `query.exe`.

Wazuh generated alerts mapped to parent technique `T1087`, but not specifically to `T1087.001`.

Result: behavioral execution partial, telemetry present, parent-technique detection present, sub-technique mapping incomplete.

### T1016

Atomic executed network discovery commands including `ipconfig`, `netsh`, `arp`, `nbtstat`, and `net config`.

Sysmon recorded the expected processes.

Wazuh generated alerts, but the observed mappings did not identify `T1016`.

Result: telemetry and alerting present, ATT&CK mapping gap.

### T1059.001

Atomic executed a benign Base64-encoded PowerShell command that printed:

`Hello, from PowerShell!`

Sysmon recorded `powershell.exe -e ...`.

Wazuh rule `92057`, level 12, detected the encoded PowerShell execution and correctly mapped it to `T1059.001`.

Result: full validation PASS.

## Important observation

Some PowerShell and `net user` activity observed during analysis originated from Wazuh Agent security configuration assessment activity running as `SYSTEM`.

Those events were not treated as Atomic test evidence.

PurpleWatch validation must correlate the controlled test, endpoint, execution window, telemetry, detection rule, and ATT&CK mapping instead of relying only on matching command names.

## Security boundaries

The PW-301 validation used only reviewed, controlled lab tests.

Excluded from the initial scope:

- credential theft
- persistence
- destructive actions
- lateral movement
- arbitrary remote command execution
- uncontrolled downloads
- Mimikatz/BloodHound-style tests
- Atomic payload installation

## Outcome

The Atomic Red Team validation framework is operational.

All five P0 behaviors produced observable Sysmon telemetry.

All five produced Wazuh alerts, but only `T1059.001` was observed with the exact expected ATT&CK mapping.

These mapping gaps provide the baseline for the PurpleWatch detection-engineering and retest workflow.
