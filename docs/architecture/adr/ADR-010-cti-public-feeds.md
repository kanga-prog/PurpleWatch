# ADR-010 — CTI via feeds publics normalisés

**Statut : accepté**

## Contexte

L'enrichissement CTI doit conserver provenance et qualité des données.

## Décision

Ingestions depuis feeds publics, normalisées par PurpleWatch.

## Conséquences

Validation de schéma, provenance, date d'observation, expiration et limites de taille sont requises.

## Alternatives

Copie manuelle non tracée ou CTI propriétaire : non retenues pour le MVP.
