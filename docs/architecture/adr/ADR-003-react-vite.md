# ADR-003 — Frontend React + Vite

**Statut : accepté**

## Contexte

Le MVP nécessitera une visualisation claire de couverture et des gaps.

## Décision

Adopter React avec Vite quand le frontend sera autorisé.

## Conséquences

Frontend séparé et rapide ; verrouillage npm, SAST JavaScript/TypeScript et audit npm requis.

## Alternatives

Frontend serveur ou autre framework : non retenus afin de standardiser l'interface MVP.
